# AI產業技術島

把台灣 39 個 AI 整合示範場域與 50 件 AI 應用躍昇計畫，做成 14 座可以自由探索的 3D 產業島。

- 島嶼依產業聚落的位置排成 Q 版台灣（半導體在新竹、工具機在台中、水五金在鹿港、石化在麥寮、扣件在岡山……），中央山脈是 AI 中樞島。
- 點島看產業概況；點島上的建築看單一場域：產業（業者）定位、急需 AI 升級轉型的痛點、實際導入之製程段（可點開看每一段導入的 AI 技術）、預期效益。
- 島上走動的人偶穿著各產業的制服，點他們會說出這個產業的 AI 轉型需求。
- 17 條技術協作線串起各島；可搜尋、清單瀏覽、跟著小機器人「小智」導覽，並切換白天／黃昏／夜晚／清晨。

## 檔案

| 路徑 | 說明 |
|---|---|
| `index.html` | 部署用的單一檔案網站（由 `src/` 組成） |
| `og.png` | 分享預覽圖 |
| `src/data.js` | 島嶼、場域、協作線與中樞島內容 |
| `src/data2.js` | 島嶼地理位置、人偶與台詞、製程段與 AI 技術、網路補充來源 |
| `src/app.js` | three.js 場景與互動 |
| `src/style.css`、`src/index.template.html` | 樣式與頁面骨架 |
| `src/build.py` | 組合成 `index.html` |

修改 `src/` 之後執行：

```bash
python3 src/build.py
```

## 部署

純靜態網站，沒有建置步驟。Vercel 匯入此 repo 後直接部署即可（Framework Preset：Other）。

## 資料來源

經濟部產業技術司 A+ 企業創新研發淬鍊計畫報告案（AI 應用躍昇計畫，115.7.21）、AI 整體發展策略暨整合示範場域構思，及各案計畫書摘要；部分業者定位以公開新聞與公司網站補充，來源列在各場域頁面下方。網站未收錄聯絡人資訊與個別經費金額。
